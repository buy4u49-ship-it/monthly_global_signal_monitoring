# 로컬 보고서 생성 실증 — 2026년 8월 자료

작업 브랜치: `feat/local-monthly-report`. 기준 수집본은 `d8a2c12`에 저장된 2026-09-04 실행 결과다. 이번 실증에서는 새 크롤링이나 별도 모델 API 호출 없이 현재 Codex 작업에서 기사를 읽고 판정을 직접 저장했다.

PDF는 Nexeon 투자 시그널 상세 1개사와 시그널 미포착 기업의 품목동향 4개사를 담는다. 사업동향 7행 중 같은 기업의 복수 자료는 기존 PDF 정렬·선택 규칙에 따라 대표 자료가 표시된다. 채택 행 개수는 사람이 작성한 정답표에 대한 정확도 지표가 아니다.

Nexeon의 확정 자금조달 자체와 별도로, 영국 파일럿 제조시설 개발 계획을 생산 확대 시그널로 판정했다. 계약·인수 완료, 일반 재무 수치, 회사 소개·위험고지의 키워드 등은 기존 기업 귀속·타겟 기술·선행성 기준으로 구분했다. 세부 이유와 인용은 기사별 review 파일과 결과 폴더의 `reviews.json`, `decisions.json`에 남는다.

## 확인한 동작

- `node --test`: 기존 15개와 새 로컬 경로 7개, 총 22개 테스트 통과.
- 기간·UTC 경계, 기업별 중복 분리, 증거·정책 변경 시 ID 변경, 판정 누락·중복·과거 ID 차단, 원문에 없는 인용 차단, 승인 문안 누락 차단을 확인했다.
- 관련성 면제가 기업 귀속·선행성 검사를 우회하지 않음을 확인했다.
- PDF 실행 실패 시 앞서 만든 결과를 보존하고 미완성 결과 폴더를 제거함을 확인했다.
- 준비본이 수정되면 보고서 생성을 차단함을 확인했다.
- 실제 8월 자료로 prepare를 재실행해 기사 30개 모두 기존 판정을 재사용하고 대기·오류 0개임을 확인했다.
- 기존 `validate_report_inputs.mjs`로 기존 174행과 새 채택 입력을 검사했다. 기존 `outputs/latest_*`와 `public/reports/*`는 변경하지 않았다.
- 한·영 PDF 10페이지를 PNG로 렌더링해 전체 배치를 확인하고, 기업 상세와 품목동향의 본문·출처를 확대 확인했다.

## 로컬 산출물과 재실행

작업 폴더는 `outputs/local_reports/2026-08-f5e3df0fd80746ddcd01e663`이다. 최초 완성본은 그 아래 `report-G5AhT1/report_ko.pdf`, `report-G5AhT1/report_en.pdf`에 있다. 로컬 산출물은 Git에서 제외되지만 현재 작업 컴퓨터에는 보존된다. 다른 컴퓨터에서 그대로 재현하려면 `outputs/local_reports`의 준비본과 review 파일도 전달해야 한다.

```bash
npm run report:local -- prepare --month 2026-08
npm run report:local -- status --run-dir outputs/local_reports/2026-08-f5e3df0fd80746ddcd01e663
npm run report:local -- build --run-dir outputs/local_reports/2026-08-f5e3df0fd80746ddcd01e663 --python python3
```

실증에서는 ReportLab이 포함된 Codex 번들 Python을 지정했다. 다른 환경은 선택한 Python에 `requirements-python.txt`를 설치하면 된다. 저장소에 포함된 정적 Noto Sans KR 폰트로 렌더링했다.

새 수집을 연결하는 `prepare --month YYYY-MM --collect` 경로는 구현했지만 이번에는 네트워크 수집을 새로 실행하지 않았다. 따라서 현재 수집 사이트의 접속 성공률이나 기사 누락률은 검증 범위에 포함되지 않는다. 또한 기존 수집 텍스트를 근거로 검토한 결과이며 모든 원문 사이트에 다시 접속해 사실을 교차 검증한 보고서는 아니다.

이 방식은 에이전트가 직접 읽고 판단하는 로컬 작업이다. 셸 명령만으로 AI 단계까지 무인 실행되는 서비스는 아니다. 구독 사용량은 소비하며, 월별 한도 내 처리 가능량과 종량제 API 대비 실제 금액 절감률은 별도 계측하지 않았다.
