# 시그널 누락 수정과 재생성 결과

`feat/local-monthly-report`에서 2026-09-06 수정. 기존 기준을 지킨다는 이유로 전조 활동까지 배제하던 문제와 로컬 검토 전에 후보가 탈락하는 문제를 수정했다.

## 변경

- 로컬 prepare는 분류기 결과가 아닌 해당 월 원자료 전체를 사용한다. 각 기업·기사에 5개 투자 지표와 사업동향 판정을 요구한다. 기술 키워드 탈락·관련성 면제 기업도 검토에서 사라지지 않는다. 별도 분류 결과 파일 없이 수집본과 수집 기간만으로 준비할 수 있다.
- `precursor`는 지표 1·3·4·5의 구체적 공급망 대응·투자 목적 조달·기술협업·전략 인력 활동이다. 최종 시설투자·인수 확정 또는 완료는 계속 제외한다. 생산 확대 지표 2는 `precursor`를 사용할 수 없다. 기업 귀속, 기술 연결, 구체적 활동 근거도 여전히 필수다.
- API 프롬프트, 로컬 판정, 입력 검증기, PDF의 단계 해석을 맞췄다. 투자 프롬프트는 v8, 사업동향은 v10이다. 이전 API 캐시는 새 판정에 재사용되지 않으며 로컬 정책 ID도 변경됐다.
- 기술 관련성 면제 기업도 사업동향의 구체적인 활동 근거가 필요하다. 단순 배당·행사 안내를 면제만으로 승인하지 않는다.
- API를 쓰는 기존 키워드 경로에는 실제 누락된 이사 선임·한국 사절단·투자 라운드 표현을 보완했다. 이는 검토 후보 복원이며 자동 승인 규칙이 아니다.
- 보충 뉴스 검색은 공식 링크 개수 대신 상세 본문·날짜 보강 후 사용 가능한 해당 월 자료로 결정한다. 날짜 미상·기간 밖·본문 실패 자료가 보충 검색을 막지 않는다. 기존 요청 간 대기 설정을 유지한다.
- 로컬 결과의 `coverage.json`에 월 자료 없음·근거 확인 보류·검토 완료를 구분한다. PDF 매트릭스도 확인 보류 기업을 검토 후 미포착에 넣지 않는다.

## 같은 8월 수집본으로 확인한 결과

| 항목 | 수정 전 로컬 | 수정 후 |
|---|---:|---:|
| 검토 입력 기업·기사 | 30 | 195 |
| 승인 투자 근거 행 | 1 | 8 |
| 투자 상세 기업 | 1 | 4 |
| 승인 사업동향 행 | 7 | 13 |
| 한글·영문 PDF | 각각 5페이지 | 각각 7페이지 |

투자 상세는 Charles River, Amkor Technology, Applied Materials, Nexeon이다. Applied Materials의 공동연구를 다루는 기사 2개가 같은 지표에 속하므로 8개 근거 행은 매트릭스 7칸에 대응한다. 실제 PDF는 기존 대표 기사 선택 규칙을 사용한다. 시그널이 없는 기업의 품목동향은 Albemarle, Ouster, NXP 3개사다.

복원 사례는 바이러스 검증 연구협업, EPIC 공동연구, 반도체 재무·운영 인력 영입, 한국 사절단의 사업 기회 탐색, 실리콘 음극재 상용화 자금조달·전략 투자다. Amkor CEO 본인의 방한, 특정 한국 공장 신설 등 기사에서 확인하지 못한 내용은 주장하지 않았다.

195건은 제목·자료 상태·기술 범위에 대한 선별과 관련 후보의 본문 근거 검토를 거쳤다. 195건 모두의 완전한 원문을 확보하거나 모든 외부 사실을 교차검증했다는 뜻이 아니다. 본문 미확보·목록 페이지·기술 범위가 불명확한 자료는 `needs_review`로 기록했다. PDF 집계는 포착 4개사, 검토 자료에서 미포착 19개사, 수집근거 부족 54개사다. 일부 신호가 확인된 기업에도 추가 확인 자료가 있을 수 있으며 상세 목록은 coverage 파일에 남는다.

## 검증

- Node 테스트 27개 통과. 원자료 전체 후보 생성, 미완성 판정 차단, 기술 면제 기업의 활동 근거, 전조와 확정 투자 구분, 수집 보충 판단을 포함한다.
- 실제 기존 분류기에 저장 원자료를 넣어 선임 지표 5, 방한 지표 5, 자금조달 지표 3 후보가 복원됨을 확인했다.
- 실제 Python PDF 승인 함수를 실행해 연구 전조 허용, 완료·확정·불명확·미지정 단계 차단, 생산 확대의 전조 우회 차단을 확인했다.
- 새 입력 8개 투자·13개 사업동향은 기존 입력 검증기를 통과했다.
- 한·영 PDF를 실제 빌드하고 14페이지를 PNG로 렌더링해 전체 배치를 확인했다. Nexeon 한글 상세와 Applied Materials 영문 상세는 확대 확인했다.
- prepare 재실행 시 동일 준비본과 195개 판정이 재사용되고 대기·오류가 없음을 확인했다.
- 이번 수정에서 새 전체 크롤링이나 유료 모델 API 호출은 실행하지 않았다. 외부 사이트의 최신 접근 성공률 및 실제 API 응답 품질은 별도 검증되지 않았다.
